PROJECTION ROOM · TV FOCUS SPEC v2

边框发泡＝聚焦

不用额外套一圈白，也不改组件自己的边框颜色。聚焦时让这根边框自己鼓起来：变粗、向外涨、透出同色柔光、整个元素轻微放大。像气泡从内部顶出来，比套一圈硬线更像"活的"。

01

规则

颜色不动，形态动

金色边框就保持金色，白色就保持白色。焦点只改三件事：

静止1dp 细边
① 静息：1dp
无光晕、无缩放
聚焦3dp 鼓起
② 发泡：3dp + 同色光晕
+ 放大 1.04

「选中」和「聚焦」怎么分开

两者可以都是金色，但位置不同、动静不同：

选中内描边·静
③ 选中：内描边 1.5dp
金底、不发泡
选中+聚焦内静外涨
④ 叠加：内实线 + 外发泡
关键：发泡只发生在外侧（向外 2~3dp 生长），不挤压内层；内层金边固定不动。所以「这是当前项」是一条细实线，「我停在这里」是一圈鼓起的柔光，一静一动，不会看混。

发泡过程

220 ms 内完成，带 3% 过冲（先鼓过头再收回），这是"弹出来"的手感来源。

线条由细到粗、光晕由无到有、尺寸先过冲再回落，三者同步才叫"发泡"。只放大不增粗像抖动，只增粗不发光像描边加粗，都不够。
实时预览循环发泡
左边这张卡在循环演示：静息 → 鼓起（带过冲）→ 定格 → 收回。真机上这就是遥控器停上去 0.2 秒内发生的事，然后一直保持鼓起，直到焦点移走。

06

行为规则

  • 落焦：进页面必落第一个可交互项；空态落在「重试 / 返回」，不允许无焦点。
  • 不丢焦点：切 tab、开关弹窗、刷新列表后显式 requestFocus 并重试 2~3 次（Compose 焦点树重建期会假成功）。
  • 可见性：聚焦项离滚动边缘 ≥ 48 dp，发泡空间要算进去，别被顶栏裁掉。
  • 控制条：3 秒无操作收起，收起后焦点回播放键；焦点移动算操作并重置计时。
  • 弹窗：打开聚焦首个按钮，关闭还给触发元素。
  • 性能：发泡用 drawBehind 多层圆角矩形绘制，动画走 graphicsLayer，不要每帧重组。
